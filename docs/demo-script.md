# Сценарий демонстрации (5–7 минут)

Все данные синтетические. Пароль всех демо-аккаунтов — `Demo-Password-2026` (или значение `SEED_DEMO_PASSWORD`). В шапке демо-аккаунты помечены бейджем
«Демоаккаунт». ФСП-достижения — демонстрационная интеграция.

## Подготовка (за 10 минут до показа)

1. Поднять стенд и демо-данные ([README](../README.md), разделы «Быстрый запуск»); для чистого состояния выполнить сброс демо-данных:
   `pnpm --filter @fsp/api db:seed:reset` (на хосте) или `docker compose --profile seed run --rm seed node dist/scripts/seed.js --reset` (в Docker).
2. Открыть два **независимых окна браузера** (обычное и приватное) — кандидат и работодатель, чтобы сессии не пересекались; третья вкладка — Mailpit
   `http://localhost:8025`.
3. Проверить, что приложение отвечает: `http://localhost:3000/login`; API: `http://localhost:3001/api/v1/health/ready`.
4. Держать под рукой `docs/validation-results.md` (раздел 1.2) и `docs/submission.md`.

## Что подчеркнуть жюри

* Подтверждённая категория — результат серверной проверки; интерфейс и API не отдают ключи.
* Неуспех не понижает и не выдаёт грейд; повтор того же уровня — по правилам (24 часа / 90 дней), нижний уровень — сразу.
* Обезличенная карточка и PDF строятся **одним презентером**; контакты раскрываются только принявшей компании и пропадают после отзыва.
* Подбор объясним и воспроизводим; ФСП — бонус 5 из 100, а не обход условий; кандидат без ФСП не наказывается.
* Всё, что не сделано (проверка компаний, ATS, OCR сканов резюме, проверка на реальных телефонах), названо в `docs/implementation-status.md` и не выдаётся за готовое.

## Если что-то пошло не так

| Симптом | Действие |
|---|---|
| Не приходит письмо при регистрации нового кандидата | Открыть Mailpit (`http://localhost:8025`); проверить, что в Docker задан `DOCKER_SMTP_HOST` по умолчанию (`mailpit`) и что контейнер почты работает |
| Ответ `429` при входе или регистрации | Сработало ограничение частоты (в памяти API): подождать или перезапустить API |
| Нужны чистые данные | Сброс демо-данных (см. «Подготовка»); использованные одноразовые коды ФСП освобождаются |
| ФСП-код «уже использован» | Сброс демо-данных или другой свободный код из [fsp-integration.md](fsp-integration.md) |
| Карточка кандидата показывает «Приглашение уже отправлено» | Выбрать другого кандидата из подборки |
